**BMI Calculator Jetpack Compose**

Es una aplicació mòbil per a Android que esta desenvolupada amb **Kotlin** i amb **Jetpack Compose** que ens permet calcular 
l'Índex de Massa Corporal d'un usuari de una manera rapida i tambe de manera personalitzada.

Branques 
**main**: Conté el codi de la versió base amb la interfície estàndard i funcional.
